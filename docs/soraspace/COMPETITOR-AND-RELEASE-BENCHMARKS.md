# Product benchmarks and release gaps

The supplied screenshot is Macro's comparison with Notion. It is not evidence of Notion's current interface. Live Notion access was blocked in this workspace; no current feature-by-feature or price audit is claimed.

SoraSpace should compete through dependable connected workflows: a document with its sources, a project with its contacts and billable time, and a public site/store linked to the same private workspace. More menu items alone are not a competitive advantage. Familiar-workflow references on public app previews describe app categories, not verified feature parity, affiliation or replacement guarantees.

## Release checks

- Signup with another email, verification, service selection, invite claim and sign-in; exercise manual approval, public trial off/on, expiry, owner extension and suspension. Do not send real mail or enable payments as a test without Claudia's instruction.
- Ordinary browser app tabs; selecting an existing app preserves its document; selected files open from their filenames; sidebar hover/pin, keyboard focus, phone drawer and tablet layout remain usable.
- Measure cold/warm app start and file restore separately on representative hardware/network; record p50/p95 before making speed claims. Existing heavy WASM builds need native-side optimisation.
- Test round-trip native formats and exports, Zotero compatibility when supplied, crash recovery before advertising autosave, and downloadable backups.
- Verify private files are owner-only at the API as well as in the UI. Platform owner status does not grant access to other users' private file contents. Group sharing needs explicit audited ACLs and transactional enforcement before release.
- Validate all 16 supported locale pages, device language/override, light/dark system appearance, 320 px phone through large-monitor layouts and real native app layouts. Translations still need native-speaker review; the native apps are not automatically translated by the website.
- HobbyNest: catalogue editing/imports, images, variants/colour stock, dispatch estimates, physical/digital independent switches, packed weights/dimensions and authenticated shipping quotation. Payment/webhook/refund/stock reservation and digital fulfilment must pass sandbox end-to-end checks before any paid launch.
- Paid SoraSpace: approve starting prices and seat totals, tax treatment, recurring billing, invoice/payment status, upgrades/downgrades, cancellation and webhook retries. Checkout remains unavailable; switches do not make an unfinished payment system live.
- Multi-workgroup provisioning (5–250 seats), multiple stores, shared contacts/CRM, mail merge, integrated Projects billing, hosted regional storage setup and autosave remain staged work, not currently delivered services.

Public preview screenshots are illustrative until Claudia supplies genuine app screenshots. Keep ready, beta, desktop-only and planned labels factual. Independent security review remains necessary; AI-assisted review is not a security certification.
