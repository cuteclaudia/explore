# Kōbō v1.3 freeze decision

**Agreed and frozen on 27 October 2026**, based on Claude's supplied revision 4. Canonical specification: [storage-contract-v1.3.md](storage-contract-v1.3.md). The supplied proposal is retained unchanged at [proposals/storage-v1.3-revision-4.md](proposals/storage-v1.3-revision-4.md).

All three outstanding corrections are present:

- Cross-connection Save a Copy publishes only the destination main `library/head.json`, with a stable copy-generation UUID. It never modifies a destination registry, refuses a different existing main, and verifies its own already-committed generation after a lost reply without rewriting it.
- There is one new named operation, `selectConnection`, plus optional connection targeting on existing operations.
- Index backup/restore is a recovery requirement, explicitly not a delivered website feature.

The accepted registry bounds, atomic conditions, source-generation freeze, original verification, readonly source access, scope isolation, explicit switching and reply/change order remain intact. Cleanup remains disabled. The main remote path and existing main browser namespace are preserved.

The canonical document changes the proposal's approval/status headings and makes implementation status explicit. It does not add another operation or change the agreed copy behavior. It is the replacement for earlier “not yet frozen” decisions; previous reviews remain historical records.
