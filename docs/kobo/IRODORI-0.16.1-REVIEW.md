## What the current website supplies

Both the normal workspace and owner preview are **device-only identity sessions**. They expose the signed-in account, report storage unavailable/read-only with an empty connection ID, and refuse cloud file operations. Thus their native recovery is account-scoped/no-connection recovery. Changing the website's selected Google/kDrive provider does not yet bind Irodori to that provider or promise a connection-change notification in these wrappers. Per-connection behavior above was tested with simulated connected statuses, not live Drive/kDrive.

Sign-out/account revocation must still tear down immediately; the native “account changed” notice is not permission to retain another account's live canvas. Best-effort asynchronous recovery is not guaranteed to finish during forced teardown. Future user-initiated switching and cloud sessions still require the agreed protocol and pending storage work.
