# 46. Neighbourhood noticeboard

A friendly local noticeboard: dated notices, a guide to local groups and services, and a contact for residents.

**Suits:** Residents’ associations, Street groups, Village committees, Progress associations
**Category:** organisation · **Status:** preview · **Base layout:** Canvas (`canvas`) · **Setup purpose:** `personal`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** compact
