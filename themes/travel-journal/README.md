# 26. Travel journal

A neutral travel journal for tenants: a full-bleed landscape, the latest trip, earlier journeys and a strip of photographs.

**Suits:** Travellers, Hikers, Road-trippers, Expats
**Category:** personal · **Status:** preview · **Base layout:** Horizon (`horizon`) · **Setup purpose:** `personal`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** comfortable
