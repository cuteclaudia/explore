# 48. Open-source project

Developer-friendly: monospaced headings, documentation cards, a release list with versions and the contributors.

**Suits:** Open-source projects, Developer tools, Community software, Research software
**Category:** organisation · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** compact

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Articles — shown as **Docs**
- Blog — shown as **Releases**
- About — shown as **Contributors**
- Contact — shown as **Community**

## Layout

- Header: `split` · Hero: `split` · Maximum width: 1180px
- Home sections, in order: `cards` (articles), `list` (blog), `people` (about), `cta`
- Headings: mono stack, weight 700 · Body: sans stack · Corner radius: 6px
