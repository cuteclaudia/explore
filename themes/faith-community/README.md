# 43. Faith community

Welcoming and calm, for any faith: gathering times, who the community is, news and a warm invitation to visit.

**Suits:** Churches, Mosques, Temples, Synagogues, Meditation groups
**Category:** organisation · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** comfortable
