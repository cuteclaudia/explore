# 3. Restaurant & café

Opening hours, location and bookings first, then the menu and the food. Bold slab headings and warm colours.

**Suits:** Cafés, Restaurants, Food vans, Bakeries
**Category:** business · **Status:** preview · **Base layout:** Practice (`practice`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Articles — shown as **Menu**
- Galleries — shown as **Gallery**
- About

- Header: `bar` · Hero: `full-bleed` · Maximum width: 1180px
- Home sections, in order: `facts`, `list` (articles), `gallery` (galleries), `contact` (contact)
- Headings: slab stack, weight 700 · Body: sans stack · Corner radius: 6px
