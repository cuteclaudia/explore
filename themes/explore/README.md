# 0. Explore

The original Explore look from claudiagilbert.com, recorded as a tenant theme: travel, photography and journal writing with a full-bleed landscape hero.

**Suits:** Travellers, Photographers, Personal journals
**Category:** personal · **Status:** reference · **Base layout:** Horizon (`horizon`) · **Setup purpose:** `creative`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- About
- Journal
- Galleries — shown as **Photography**
- Contact

## Layout

- Header: `split` · Hero: `full-bleed` · Maximum width: 1300px
- Home sections, in order: `cards` (journal), `gallery` (galleries), `cta`
- Headings: serif stack, weight 400 · Body: sans stack · Corner radius: 10px
