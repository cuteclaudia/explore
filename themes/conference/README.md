# 45. Conference & event

Energetic and organised: the dates and venue, the programme with times, speakers and a strong register button.

**Suits:** Conferences, Festivals, Symposiums, Meetups, Workshops
**Category:** organisation · **Status:** preview · **Base layout:** Practice (`practice`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Articles — shown as **Programme**

- Header: `split` · Hero: `statement` · Maximum width: 1180px
- Home sections, in order: `facts`, `list` (articles), `people` (about), `cta`
- Headings: geometric stack, weight 800 · Body: sans stack · Corner radius: 12px
