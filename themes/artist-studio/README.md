# 2. Artist studio

Warm paper tones and a loose grid for painters, illustrators and makers of physical work, with a studio journal beside the gallery.

**Suits:** Illustrators, Painters, Ceramicists, Textile artists
**Category:** creative · **Status:** preview · **Base layout:** Horizon (`horizon`) · **Setup purpose:** `creative`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Galleries — shown as **Work**
- Journal — shown as **Studio notes**
- About
- Contact

- Header: `centered` · Hero: `split` · Maximum width: 1180px
- Home sections, in order: `gallery` (galleries), `cards` (journal), `intro` (about), `contact` (contact)
- Headings: oldstyle stack, weight 500 · Body: humanist stack · Corner radius: 4px
