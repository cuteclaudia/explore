# 49. Cause & campaign

Bold and urgent, in non-partisan colours: the aim, the progress so far, updates and a clear way to support.

**Suits:** Advocacy groups, Local campaigns, Fundraisers, Petitions, Community projects
**Category:** organisation · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- About — shown as **Our aims**
- Blog — shown as **Updates**
- Galleries
- Contact — shown as **Get involved**

## Layout

- Header: `split` · Hero: `banner` · Maximum width: 1180px
- Home sections, in order: `intro` (about), `facts`, `cards` (blog), `cta`
- Headings: condensed stack, weight 800, uppercase · Body: sans stack · Corner radius: 4px

## Notes

- Colours chosen to avoid association with any political party. Tenants supply their own campaign colours if they wish.
- Donation and petition services are not embedded; tenants can link to them.
