# 19. Research group

Academic and tidy: research themes, people, a citation-style publications list and group news.

**Suits:** Research labs, Research centres, PhD groups, Academic projects
**Category:** education · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `academic`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** compact

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- About — shown as **People**
- Articles — shown as **Publications**
- Blog — shown as **News**
- Contact

## Layout

- Header: `split` · Hero: `text` · Maximum width: 1180px
- Home sections, in order: `intro` (about), `list` (articles), `people` (about), `cards` (blog)
- Headings: serif stack, weight 600 · Body: sans stack · Corner radius: 4px
