# 21. Podcast

The latest episode up front, an episode list with running times, hosts and a subscribe call to action.

**Suits:** Podcasts, Radio shows, Audio series
**Category:** creative · **Status:** preview · **Base layout:** Editorial (`editorial`) · **Setup purpose:** `writer`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Blog — shown as **Episodes**
- About — shown as **Hosts**
- Contact

## Layout

- Header: `split` · Hero: `split` · Maximum width: 1180px
- Home sections, in order: `feature` (blog), `list` (blog), `intro` (about), `cta`
- Headings: geometric stack, weight 700 · Body: sans stack · Corner radius: 14px

## Notes
