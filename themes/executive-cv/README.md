# 28. Executive CV

A polished professional profile for senior people: summary, career history, selected insights and contact.

**Suits:** Executives, Board members, Senior professionals, Contractors
**Category:** personal · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** compact

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

## Layout

- Header: `split` · Hero: `split` · Maximum width: 1000px
- Home sections, in order: `intro` (about), `list` (articles), `cards` (blog), `contact` (contact)
- Headings: serif stack, weight 500 · Body: sans stack · Corner radius: 2px
