# 8. Magazine

A multi-column front page with a bold lead story, category labels and a news list, for newsletters and online magazines.

**Suits:** Online magazines, Local news, Newsletters, Student publications
**Category:** writing · **Status:** preview · **Base layout:** Editorial (`editorial`) · **Setup purpose:** `writer`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** compact

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Articles — shown as **Stories**
- Blog — shown as **News**
- About

## Layout

- Header: `centered` · Hero: `statement` · Maximum width: 1280px
- Home sections, in order: `feature` (articles), `cards` (articles), `list` (blog)
- Headings: didone stack, weight 700 · Body: sans stack · Corner radius: 0px
