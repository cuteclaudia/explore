# 9. Musician & band

Dark and loud: a full-bleed opening image, upcoming gigs first, then photos, story and booking contact.

**Suits:** Musicians, Bands, DJs, Choirs
**Category:** creative · **Status:** preview · **Base layout:** Horizon (`horizon`) · **Setup purpose:** `creative`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- Blog — shown as **Gigs & news**
- Galleries — shown as **Photos**
- About
- Contact — shown as **Bookings**

## Layout

- Header: `minimal` · Hero: `full-bleed` · Maximum width: 1180px
- Home sections, in order: `list` (blog), `gallery` (galleries), `intro` (about), `contact` (contact)
- Headings: condensed stack, weight 800, uppercase · Body: sans stack · Corner radius: 4px
