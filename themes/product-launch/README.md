# 15. Product launch

Modern and bold: a big headline, feature blocks, product updates and a sign-up call to action for apps and startups.

**Suits:** Startups, Apps, Software products, Side projects
**Category:** business · **Status:** preview · **Base layout:** Practice (`practice`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** yes · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- About — shown as **Features**
- Blog — shown as **Updates**
- Contact — shown as **Get early access**

## Layout

- Header: `split` · Hero: `statement` · Maximum width: 1180px
- Home sections, in order: `cards` (about), `feature` (blog), `cta`
- Headings: geometric stack, weight 800 · Body: sans stack · Corner radius: 16px
