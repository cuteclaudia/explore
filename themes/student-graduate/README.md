# 17. Student & graduate

A simple CV-style site: who you are, projects, skills and how to get in touch. Built for students and job seekers.

**Suits:** Students, Graduates, Job seekers, Interns
**Category:** personal · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `student`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- About
- Articles — shown as **Projects**
- Contact

## Layout

- Header: `minimal` · Hero: `text` · Maximum width: 920px
- Home sections, in order: `intro` (about), `list` (articles), `facts`, `contact` (contact)
- Headings: sans stack, weight 700 · Body: sans stack · Corner radius: 8px
