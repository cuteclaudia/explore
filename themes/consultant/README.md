# 6. Consultant

A clean personal-brand site: who you are, what you help with, selected work and writing, with one confident accent colour.

**Suits:** Independent consultants, Coaches, Freelancers, Speakers
**Category:** business · **Status:** preview · **Base layout:** Folio (`folio`) · **Setup purpose:** `business`
**Recommended visibility:** public · **Workgroup friendly:** no · **Density:** comfortable

## Pages used

Only the existing SoraSpace page types are used. Labels are display names; the underlying page type is unchanged.

- Home
- About
- Articles — shown as **Work**
- Blog — shown as **Writing**
- Contact

## Layout

- Header: `split` · Hero: `split` · Maximum width: 1180px
- Home sections, in order: `intro` (about), `cards` (articles), `feature` (blog), `cta`
- Headings: geometric stack, weight 700 · Body: sans stack · Corner radius: 12px
